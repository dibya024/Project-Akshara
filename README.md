# Akshara

Akshara is a modern social media and messaging dashboard UI built with React and Vite. It presents a dark-themed, chat-focused workspace with a left navigation rail, a central conversation area, and a right sidebar for recent chats.

## Overview

This project is designed to resemble a messaging/social platform where users can:

- browse a left-side navigation stack
- view recent conversations in a resizable right sidebar
- open a detailed chat panel from the conversation list
- interact with a clean, minimal UI tailored for chat and communication workflows

## Features

- Responsive dark-mode interface
- Resizable left and right sidebars
- Recent chat list with quick conversation entry
- Detailed conversation view with message composer
- Clean component-based structure using React
- Fast development workflow with Vite

## Tech Stack

- React 19
- Vite
- JavaScript
- CSS modules / custom CSS
- Lucide React icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

This starts the Vite development server, typically available at:

```text
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
